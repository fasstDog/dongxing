# 空态与文案规范

> 配套静态原型：加载中 / 无方案 / 数据失败的人话说明。只推荐不卖票；大陆口语短句；价格、时刻均为参考，不承诺出票。  
> 更新日期：2026-09-22（人话抽检 + 空态走查）

---

## 查询页

| 触发条件 | 界面行为 | 人话文案 |
|----------|----------|----------|
| 出发地或目的地为空，点「开始邪修」 | **就地 Toast**，不跳结果页 | 先填出发地和目的地 |
| 出发地 = 目的地（去空格后相同） | Toast，不跳结果 | 出发和到达不能是同一个地方 |
| 途经已达 3 个，再点「添加途经城市」 | 按钮 **禁用**；若仍触发则 Toast | 途经最多 3 个 |
| 途经城市与出发或到达重复 | Toast，不跳结果 | 途经别和出发/到达重复 |

说明：校验失败一律留在查询页；途经上限以按钮禁用为主，文案与 Toast 一致。

## 结果页

### 加载中

| 触发 | 界面 | 文案 |
|------|------|------|
| 校验通过后进入结果 | 结果区加载态约 **600–900ms**（演示约 700ms）再出内容 | 正在邪修组合… |

加载期间隐藏三主卡与「更多方案」。

### 无方案（空态）

| 触发 | 界面 | 文案与动作 |
|------|------|------------|
| 演示开关「演示：无方案」打开后查询；或未来真实无命中 | 空态区：说明可能原因 + 按钮 | **这趟暂时拼不出方案**<br>可能是城市名不好认、日期太偏，或这条线我们还没覆盖好。价格时刻都是参考，不保证有票。<br>**改查询条件** → 回查询页<br>**看看示例：徐州→拉萨** / **看看示例：上海→成都** → 填入对应 OD、关演示开关、成功出 mock 结果 |

### 失败（数据暂不可用）

| 触发 | 界面 | 文案与动作 |
|------|------|------------|
| 演示开关「演示：加载失败」打开后查询；或未来接口失败 | 失败态区 + 两个按钮 | **这趟没查到，多半是数据暂不可用**<br>副文：价格、时刻都是参考，不保证有票。也可以改条件再查。<br>**再试一次** → 重跑当前查询（演示开关仍开则可再失败）<br>**改条件** → 回查询页 |

### 演示开关（查询页底部，小字）

- 「演示：无方案」「演示：加载失败」
- **默认关闭**；正常路径默认徐州→拉萨 mock，也可切上海→成都样例。
- 两个开关互斥：打开其一则关掉另一个。
- 仅原型用，帮助 stakeholder 稳定复现，不代表线上会有此入口。

## 方案详情

| 触发 | 行为 |
|------|------|
| 无效 / 未知 plan id | Toast「方案找不到了，先回结果看看」并回结果页（结果可展示时）；否则回查询 |

购票区统一句：**我们不卖票。去 12306 / 航司 / OTA 自己买。**

## 语气约定

- 大陆口语、短句，像朋友说话；忌客服腔、公文腔、堆砌形容词。
- 不承诺出票，不写「一定有票 / 帮你买到」。
- 价格、时刻带「参考」意识；失败归因偏「数据暂不可用」，不甩锅用户。
- 「为什么」说人话：讲清楚怎么走、贵在哪 / 省在哪 / 省时间在哪；少写「系统选枢纽拆段」「程序打分」这类工程句。
- 「怎么玩」只在换乘空窗够长时出现；不够长就说接驳、别硬推景点。
- 统一可用短句（可按场景微调）：
  - 价格、时刻都是参考，不保证有票。
  - 空窗够长才写怎么玩；不够长不会硬推景点。
  - 只推荐路线，不卖票。

### 方案「为什么 / 怎么玩」示例（沪蓉）

对照用；写 mock / 模板时对齐这个调性，忌「系统选枢纽」「综合参考价与时长」。

| 字段 | 别这样写 | 人话示例 |
|------|----------|----------|
| path_note | 系统选枢纽：武汉 | 系统帮你挑了武汉换乘 |
| path_note（指定途经） | 因你指定经 武汉 | 按你指定经武汉 |
| why（省钱过夜） | 经 武汉 拆段。多一趟换乘… | 先高铁到武汉，再坐过夜火车去成都。参考价能省几十块，但要多花大半天；换乘够长能顺路逛逛。 |
| why（高铁快） | 经 西安 的高铁组合，门到门更短。 | 先高铁到西安北，再换乘去成都。比直达贵一截，但能少耗大约 1 小时。 |
| tip（同城） | 预留接驳时间 | 武汉站到汉口站要同城倒一下，留足地铁/打车时间 |
| play.ok（空窗短） | 同站缓冲约 ≥2 小时：不硬推出城 | 同站大概空 2 小时：就在站里歇会儿，别硬推出城 |
