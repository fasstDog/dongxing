# 技术与设计拍板（负责人，2026-09-22）

用户授权负责人直接拍板。产品原型须达到可对外演示的保真度。开发**禁止造轮子**，优先成熟开源框架/组件。

## 头部枢纽（MVP 锁定）

北京、上海、广州、深圳、成都、重庆、武汉、杭州、郑州、西安、兰州、西宁。

每城维护 3～6 个「怎么玩」POI（距车站、建议游玩时长、是否赶得回）。

## 技术原则

| 层 | 选型原则 |
|----|----------|
| Web 原型 UI | Vant 或 TDesign Mobile（CDN/npm），不自研设计系统 |
| 微信小程序（后续） | Vant Weapp 或 TDesign 小程序，前端择一并写进 README |
| 规则引擎 | TypeScript/Node 普通服务即可；先 mock JSON |
| 数据 | 合规数据源；密钥不进仓；禁止违规爬取 |
| 地图/接驳（后续） | 优先官方/合规 SDK，不自研路网 |

## 产品不变

只推荐不卖票；三主卡（最省钱/最快/最综合）+ 更多；怎么去·为什么·怎么玩·外链购票；出计划程序算，模型不编车次票价。
