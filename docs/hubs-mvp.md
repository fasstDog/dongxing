## 「怎么玩」出现规则（摘要）

| 条件 | 行为 |
|------|------|
| 同站缓冲 ≥ 约 2 小时 | 偏休息 / 站内或极近 |
| 同城缓冲 ≥ 约 3 小时 | 可推 1～2 个景点 |
| 过夜或 ≥ 约 6 小时 | 可推半日玩 |
| 低于阈值 | 只提示休息与接驳，**不硬推景点** |

完整 POI 行（名称、距站、建议游玩时长、是否赶得回）将另文件维护（如 `data/hub-pois.json`），本文件只定城与锚点。
