# 架构 · 小程序前端（正式交付）

> 对齐总架构 [`邪修交通-系统架构设计_v1.0.md`](./邪修交通-系统架构设计_v1.0.md) 第1/3/8章  
> 产品边界见 [`架构-产品与体验.md`](./架构-产品与体验.md)  
> 引擎契约见 [`架构-规则引擎.md`](./架构-规则引擎.md) 与 `api-plans-contract.md`  
> **根目录 HTML/Vue 原型冻结，正式前端仅微信小程序 + Vant Weapp。**

## 1. 职责与红线

| 做 | 不做 |
|----|------|
| 查询 → 三主卡 → 详情 → 关于 | 卖票 / 支付 / 登录 / 账号 |
| 加载 / 空 / 失败三态（规范文案） | 在端上枚举 MCT、编造车次票价 |
| 薄适配层：`PlansSearchResponse` → UI | 直连供应商 API、嵌入密钥 |
| 外链购票示意（12306/OTA） | 自研设计系统（只用 `@vant/weapp`） |

原则：**程序算出计划，前端只展示与导航。** `ok:false` 必须走空/失败态，禁止静默编造方案。

## 2. 页面栈

```
pages/query     出发/到达/可选日期/有序途经(≤3) + 样例 OD + 演示三态开关
pages/results   加载 → 三主卡(cheap/fast/balanced) + 更多；空/失败三态
pages/detail    怎么去时间轴 · 为什么 ·（可选）怎么玩 · 分段外链购票
pages/about     只推荐不卖票 · 免责 · 数据说明
```

信息架构与文案以产品架构 / `空态与文案规范` 为准；交互细节见 `小程序-查询与三主卡交互要点.md`。

## 3. 与引擎/数据的边界

```
[小程序]  --POST /v1/plans/search-->  [引擎服务]
         <-- PlansSearchResponse --
                    ↑
              adapters → Leg[] / TransferPlay
```

| 阶段 | 前端数据来源 |
|------|----------------|
| **M0（当前）** | 本地 `miniprogram/data/plans-*.json`（pipeline 预导出，等同一次离线 `searchPlans`） |
| **M1** | 同一契约，改走 HTTPS `POST /v1/plans/search`（仍可 mock 后端） |
| **M2+** | 真源在引擎侧切换；前端适配层字段不变 |

适配层（`utils/adapt-plans.js`）：

- 输入：契约 snake_case（`main[]` / `more[]` / `timeline` kind=`leg|xfer`）
- 输出：页面 camelCase；`service_ref` **原样透传**，不改写车次
- pipeline 槽位 `cheapest|fastest|balanced` 与 API `cheap|fast|balanced` 在适配层归一

## 4. 技术选型（拍板）

| 项 | 选择 |
|----|------|
| 运行时 | 微信小程序 |
| UI | `@vant/weapp`（禁止自研组件库） |
| 状态 | 页内 data + `globalData.lastQuery`；MVP 不做全局 store |
| 网络 | `wx.request`；超时/非 2xx → 失败态文案 |

## 5. 组件与三态

- 查询：`van-field` / `van-button` / `van-switch` / `van-tag`
- 结果：`van-loading` / `van-empty` / 卡片列表；空态提供样例 OD 一键填入
- 详情：时间轴（火车/飞机样式）+ why + play + 购票 Toast/外链
- 关于：免责与「价格时刻均为参考、不保证有票」

加载时长演示约 600–900ms；正式接 API 后以真实 RTT 为准，文案不变。

## 6. 里程碑（前端）

| 里程碑 | 交付 |
|--------|------|
| M0 | 四页壳 + 本地 JSON 三主卡/详情/三态/多 OD 样例（已有骨架） |
| M1 | `adapt-plans` 接 `POST /v1/plans/search`；去掉对预导出文件的硬依赖（可保留离线降级） |
| M2 | 真源切换无感（仍只消费契约）；性能与空态验收 |
| M3 | 小程序提审材料 / 体验优化（不引入卖票） |
