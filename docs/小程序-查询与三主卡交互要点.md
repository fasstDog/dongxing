# 小程序 · 查询与三主卡交互要点

> 给前端对照脚手架用。本阶段只迁 **查询页 + 结果页三主卡壳**；方案详情 / 关于可后补。UI：**Vant Weapp**。  
> 对照 Web 原型（`index.html`）与 [`空态与文案规范.md`](./空态与文案规范.md)；**勿发明卖票 / 登录 / 支付流程**。

---

## 1. 范围

| 做 | 不做（本阶段） |
|----|----------------|
| 查询页字段与校验 | 方案详情页完整时间轴 |

| 本地 mock 出结果（对齐现有 plans） | 真 API、登录、支付、卖票 |

---

## 2. 产品锁定

- **只推荐路线，不卖票。**
- 购票若出现，仅 **外链示意**（Toast / 跳转第三方说明即可），本小程序不出票、不收款。
- **无登录、无支付、无订单。**

---

## 3. 查询页

| 字段 | 必填 | 说明 |
|------|------|------|
| 出发地 | 是 | 城市 / 站点 |
| 到达地 | 是 | 城市 / 站点 |
| 出发日期 | 否 | 含「日期灵活」 |
| 途经城市 | 否 | **有序**，最多 **3**；支持增删（调序可后补） |

校验失败 **一律留在查询页**（Toast），文案对齐 [`空态与文案规范.md`](./空态与文案规范.md)：

| 条件 | 文案 |
|------|------|
| 出发或到达为空 | 先填出发地和目的地 |
| 出发 = 到达 | 出发和到达不能是同一个地方 |
| 途经已满 3 再添加 | 途经最多 3 个（按钮优先禁用） |
| 途经与出发/到达重复 | 途经别和出发/到达重复 |

主按钮文案可沿用 Web：**开始邪修**。

---

## 4. 结果页 · 三主卡壳

三张主卡固定顺序：**最省钱 → 最快 → 最综合**。

每卡信息层级（自上而下）：

1. **标题**：最省钱 / 最快 / 最综合  
2. **参考价**（标「参考」，不承诺有票）  
3. **总时长**  
4. **一句话为什么**（人话；对齐空态规范调性）  
5. **标识**：有换乘标换乘；含飞机段标飞机 / 空铁（与 Web 一致即可）

### 三态

| 态 | 行为 / 文案要点 |
|----|-----------------|
| 加载 | 隐藏三主卡；「正在邪修组合…」（演示约 600–900ms） |
| 无方案 | 「这趟暂时拼不出方案」+ 原因说明（含不保证有票）+ 改条件 / 看示例 |
| 失败 | 「这趟没查到，多半是数据暂不可用」+ 再试一次 / 改条件 |

完整句见空态规范；演示开关仅 Web 原型可选，小程序可不迁。

### 双样例入口（若保留）

| 样例 | 状态 |
|------|------|
| 徐州 → 拉萨 | 已有 mock，可默认 |
| 上海 → 成都 | 已有 mock |
| 北京 → 武汉（京广短途） | legs 已有，**plans 即将有，入口可预留** |

点卡进入详情：本阶段可用 Toast stub（「详情后补」），勿做购票下单。

## 5. 文案红线

- **不承诺有票**（禁用「一定有票 / 帮你买到」）。
- 价格、时刻一律标 **参考**，以购票平台为准。
- 换乘空窗不够长 → **不硬推怎么玩**（只接驳 / 休息提示即可）。
- 统一可用短句：只推荐路线，不卖票。 / 价格、时刻都是参考，不保证有票。
