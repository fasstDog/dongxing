颜色：城市 `#0e5a6b`、火车站 `#ff6b4a`、机场 `#4c5fd5`、码头 `#0a8fd8`（与 `styles/tokens.scss` 的 `$color-place-*` 一致）。

`craft-train.png` / `craft-plane.png` / `craft-ship.png`（128×128，白色、透明底）由 Tabler Icons v3.49.0 的 filled `train` / `plane` / `ferry` 导出，供过渡页载具使用。Tabler 没有 filled `ship`，客运船用 filled `ferry`。

Tabler Icons — MIT License, Copyright (c) 2020-2026 Paweł Kuna.

过渡页把白色图标放在圆形实心底上：火车 `#ff6b4a`、飞机 `#4c5fd5`、轮船 `#0a8fd8`。
