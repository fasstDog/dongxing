# 懂行 · 官方 React Native App（占位）

**正式客户端之一**：官方 React Native，**仅 iOS + Android**。

- 与微信小程序共享：`@dongxing/shared` 契约、引擎 `POST /v1/plans/search`、可抽出 TS 逻辑。
- **不是**小程序交付路径（非 Alita / 非把小程序跑进 App）。
- Win / macOS / Web / tvOS / Linux / Proton Native **不进产品范围**。

本目录为占位（`package.json` + README）。脚手架与业务实现另开任务。
